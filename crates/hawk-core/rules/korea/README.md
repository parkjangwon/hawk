# Korean Secure Coding Rule Pack (`korea`)

Hawk의 한국형 소프트웨어 보안약점 진단 룰 팩입니다. 행정안전부 및 한국인터넷진흥원(KISA)의 가이드를 기반으로 정적 분석 규칙을 제공합니다.

## 7대 보안약점 분류 체계

1. **입력데이터 검증 및 표현** (Input Validation & Representation)
   - SQL 인젝션, 크로스사이트 스크립팅(XSS), 경로 순회(Path Traversal), 명령어 삽입 등
2. **보안기능** (Security Features)
   - 하드코딩된 비밀번호/키, 취약한 암호화 알고리즘, 취약한 난수 생성기 등
3. **시간 및 상태** (Time and State)
   - TOCTOU 경쟁 상태 등
4. **에러처리** (Error Handling)
   - 부적절한 예외 처리, 스택 트레이스 노출, 에러 메시지를 통한 정보 누출 등
5. **코드오류** (Code Quality & Flaws)
   - 무한 루프, Null 포인터 역참조 등
6. **캡슐화** (Encapsulation)
   - 제거되지 않은 디버그 코드, 잘못된 접근 제어 등
7. **API 오용** (API Misuse)
   - 안전하지 않은 API 사용, DNS 룩업 기반 보안 결정 등
